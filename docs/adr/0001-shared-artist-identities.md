# Preserve credited names under a shared artist identity

Historical artist names can represent one continuing band while providers divide or combine its discography differently.
Keep each credited name as a visible library entry with its existing album credits and paths, and explicitly link related names to one canonical artist identity for provider matching, reconciliation, and metadata.
Provider artist identities and provider releases remain globally unique, while multiple provider pages owned by different credited names can supply the same canonical artist without giving that provider extra consensus votes.
